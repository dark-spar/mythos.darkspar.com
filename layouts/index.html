Principles

Six things Mythos is opinionated about.

  1. 01

    One server, the whole library.

    Films, shows, music, photos. Mythos handles the standard layouts out of the box and respects what's already on disk.

  2. 02

    Hardware-accelerated by default.

    VAAPI, QSV, NVENC, VideoToolbox. Mythos picks the right encoder automatically and keeps a 4K stream on a fan-quiet box.

  3. 03

    Private by construction.

    No phoning home. No analytics. No third-party SDK reading your watch history. The server runs on your hardware and stops there.

  4. 04

    Light on the metal.

    Under 100 MB of RAM at idle. The whole binary is 12 MB. A Raspberry Pi 5 can serve the whole household.

  5. 05

    Built for the household.

    Per-user libraries, child-safe accounts, watch-together rooms. The little choices that make the living room work.

  6. 06

    Open and inspectable.

    MIT licensed, every dependency vendored and audited. The whole codebase is small enough to read in an afternoon.

Get started

One command to running.

docker

The fastest way to try Mythos. Mounts your media directory read-only and exposes the web UI on port 7878.

docker run -d \
  --name mythos \
  -p 7878:7878 \
  -v /srv/media:/media:ro \
  -v mythos-data:/var/lib/mythos \
  ghcr.io/dark-spar/mythos:latest

binary

Static, single-file binaries for Linux, macOS, and Windows. No runtime, no dependencies.

curl -sSL https://mythos.darkspar.com/install.sh | sh
mythos --config /etc/mythos/config.toml

cargo

Build from source. You'll need Rust 1.95 or newer.

git clone https://gitlab.com/darkspar/mythos
cd mythos
cargo build --release
./target/release/mythos-server

packages

Native packages for common distros — Arch (yay -S mythos), Debian/Ubuntu .deb, Homebrew, and a NixOS flake with module.

brew install dark-spar/tap/mythos
mythos --config ~/.config/mythos/config.toml
